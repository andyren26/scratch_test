# 積木程式測驗：設定說明

學生打開網頁就能作答，不需要帳號。積木的分類、外觀和用法照 Scratch 3。因為是測驗，畫面上沒有舞台：學生只能依題目拉出積木，按「提交本題」或「交卷」時，系統在背景執行程式並評分。題目和成績都放在你的 Google 試算表裡。

| 檔案 | 用途 |
|---|---|
| `index.html` | 作答網頁，放到 GitHub Pages |
| `apps-script/Code.gs` | 貼到 Google 試算表的 Apps Script，負責讀題庫和收成績 |

整個設定大約 15 分鐘，只需要做一次。

---

## 可以用的積木

依康軒國中資訊科技課本（1 上～2 下）用到 Scratch 的單元整理：角色移動、鍵盤鋼琴、循序／重複／選擇結構、廣播與音效、模組化（我的積木、正多邊形）、陣列（清單）、排序與搜尋。

| 分類 | 積木 |
|---|---|
| 動作 | 移動、右轉／左轉、定位到（隨機位置、鼠標、x y）、滑行、面朝、x／y 改變與設為、碰到邊緣就反彈、迴轉方式、x 座標、y 座標、方向 |
| 外觀 | 說出（持續幾秒）、想著、造型換成、下一個造型、背景換成、下一個背景、尺寸、圖像效果（顏色、亮度、幻影）、顯示、隱藏、移到最上／下層 |
| 音效 | 播放音效（喵、啵、嗶、鼓聲）、停播所有音效、音量 |
| 事件 | 當綠旗被點擊、當某鍵被按下、當角色被點擊、廣播訊息（並等待）、當收到訊息 |
| 控制 | 等待、重複幾次、重複無限次、如果那麼（否則）、等待直到、重複直到、停止、分身（建立、當分身產生、刪除） |
| 偵測 | 碰到鼠標／邊緣／顏色、與鼠標的間距、詢問並等待、詢問的答案、按鍵被按下、滑鼠鍵、鼠標 x／y、計時器、目前時間 |
| 運算 | 加減乘除、隨機取數、大於／小於／等於、且／或／不成立、字串組合、字串的第幾字、字串長度、包含、餘數、四捨五入、絕對值／平方根／sin／cos 等 |
| 變數 | 建立變數、設為、改變、顯示／隱藏變數；建立清單、新增、刪除、插入、替換、第幾項、項目編號、項目數量、包含、顯示／隱藏清單 |
| 我的積木 | 建立自己的積木，可以加參數（點「定義」積木上的齒輪），可以遞迴 |
| 畫筆 | 筆跡全部清除、蓋章、下筆、停筆、筆跡顏色、筆跡寬度 |
| 音樂 | 演奏音符、休息、彈奏鼓聲、樂器、演奏速度 |

角色只有一個（有 4 種造型：機器人1、機器人2、箭頭、球），可以用分身做出多個角色。背景有 3 種：空白、座標格線、迷宮（黑色牆壁、綠色終點，可以用「碰到顏色」做電流急急棒類的題目）。

**和真正的 Scratch 不一樣的地方**：不能新增角色、不能上傳或自己畫造型、沒有文字轉語音和視訊偵測。

## 第一步：建立 Google 試算表和後端程式

1. 到 Google 雲端硬碟新增一個 Google 試算表，例如命名為「積木測驗」。
2. 點上方選單 **擴充功能 → Apps Script**。
3. 把編輯器裡原本的內容全部刪掉，貼上 `apps-script/Code.gs` 的全部內容，按 💾 儲存。
4. 上方函式選單選 **setup**，按 **▶ 執行**。
   - 第一次會要求授權：選你的帳號 → 「進階」→「前往（不安全）」→「允許」。這是你自己寫的程式，所以 Google 會這樣提醒。
   - 執行完回到試算表，會多出「**題庫**」和「**成績**」兩個工作表。

> 如果之前已經用舊版設定過：貼上新的 `Code.gs` 後再執行一次 **setup**，「題庫」會多出「評分方式」和「答案碼」兩欄，原本的題目不受影響。接著照下面「之後修改 Code.gs」的方式重新部署。

## 第二步：發佈成網頁應用程式

1. 在 Apps Script 右上角按 **部署 → 新增部署作業**。
2. 齒輪圖示選 **網頁應用程式**，設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（學生不用登入；選其他選項，學生的成績會送不出來）
3. 按「部署」，複製畫面上的**網頁應用程式網址**（`https://script.google.com/macros/s/…/exec`）。

> 之後修改 `Code.gs`：按 **部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署**，網址不變。只改試算表裡的題目則不需要重新部署。

## 第三步：把網址貼進網頁

用記事本（或 GitHub 網站上的編輯功能）打開 `index.html`，找到這一行：

```js
const SCRIPT_URL = "";  // 例如 "https://script.google.com/macros/s/AKfy.../exec"
```

把剛才複製的網址貼在引號中間：

```js
const SCRIPT_URL = "https://script.google.com/macros/s/你的網址/exec";
```

## 第四步：放到 GitHub Pages

1. 登入 [GitHub](https://github.com)，右上角 **+ → New repository**，取個名字（例如 `block-quiz`），選 **Public**，按「Create repository」。
2. 在新的 repository 頁面點 **uploading an existing file**，把 `index.html` 拖進去，按「Commit changes」。（`apps-script` 資料夾可以不用上傳。）
3. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾選 **/(root)**，按「Save」。
4. 等 1～2 分鐘，頁面上方會出現網址，例如 `https://你的帳號.github.io/block-quiz/`。把這個網址給學生就完成了。

## 出題：在「題庫」工作表填一列

| 欄位 | 說明 |
|---|---|
| 啟用 | 打勾的題目才會出現在網頁上，可以先準備好，上課時再勾選 |
| 題目名稱 | 不能重複，成績表的欄位名稱就是它 |
| 題目說明 | 給學生看的題目內容 |
| 輸入名稱 | 學生每用一次「詢問並等待」，就依序拿到下一個值；不需要輸入就留空 |
| 測資 | 一行一筆（同一格內換行按 **Alt+Enter**），**第一筆公開當範例**，其餘是隱藏測資 |
| 配分 | 這題的分數，依通過的測資比例給分 |
| 評分方式 | 說出（留空就是說出）、畫筆、角色位置、音符 |
| 答案碼 | 老師用積木寫好的參考答案，系統用它算出標準答案（見下一節） |

### 四種評分方式

| 評分方式 | 比對什麼 | 測資寫法 | 適合的單元 |
|---|---|---|---|
| 說出 | 角色依序「說出」的內容 | `5 => 15`；多個輸入 `3,8 => 8`；說出多行 `3 => 1\|2\|3` | 三大流程結構、變數、清單、排序、搜尋 |
| 畫筆 | 畫出來的圖形（筆跡顏色、粗細不影響） | 只寫輸入，例如 `5`；不需要輸入就留空。**一定要有答案碼** | 正多邊形、幾何圖形、我的積木 |
| 角色位置 | 角色最後的 x、y、方向（誤差 1 以內） | `=> x=100, y=50, 方向=90`，可以只寫其中幾項 | 角色移動、座標 |
| 音符 | 依序演奏的音符（60 是中央 Do） | `=> 60,62,64`；要比對拍數寫 `=> 60:0.5, 62:0.5` | 演奏音階、鍵盤鋼琴 |

範例：

| 啟用 | 題目名稱 | 題目說明 | 輸入名稱 | 測資 | 配分 | 評分方式 | 答案碼 |
|---|---|---|---|---|---|---|---|
| ☑ | 1. 加總 | 詢問 n，說出 1 + 2 + … + n 的總和。 | n | 5 => 15<br>10 => 55<br>100 => 5050 | 25 | 說出 | |
| ☑ | 2. 正方形 | 畫出邊長 100 的正方形。 | | | 25 | 畫筆 | SB1:… |
| ☑ | 3. 正多邊形 | 詢問邊數 n，畫出邊長 60 的正 n 邊形。 | n | 3<br>5<br>8 | 25 | 畫筆 | SB1:… |
| ☑ | 4. Do Re Mi | 依序演奏 Do、Re、Mi，每個音 0.5 拍。 | | => 60:0.5, 62:0.5, 64:0.5 | 25 | 音符 | |

格式有錯的題目不會出現在網頁上。網頁上如果一題都沒有，會列出是哪一列出了什麼問題。改完題目，學生**重新整理網頁**就會看到最新題目。

### 產生答案碼

畫筆題一定要有答案碼。其他題目有了答案碼，測資就可以只寫輸入，不用自己算標準答案。

1. 打開作答網頁，在網址最後加上 `#teacher`，例如 `https://你的帳號.github.io/block-quiz/#teacher`，重新整理。
2. 用積木寫出這題的參考答案，程式要接在「當綠旗被點擊」下面。
3. 按右上角的 **產生答案碼**，再按「複製」，貼到試算表該題的「答案碼」欄。
4. 之後要修改，可以把答案碼貼回「產生答案碼」的視窗，按「載入到程式區」。

學生作答時，畫筆題的題目卡會附一張目標圖形（畫在座標格線上，用第一筆測資算出來），角色位置題的範例會寫出終點座標與方向。

## 看成績：「成績」工作表

- 每次交卷新增一列：交卷時間、班級、座號、姓名、總分、滿分，以及每題得分（新題目的欄位會自動加上）。
- 學生重新交卷會再新增一列。只要看最新一次的話，可以依「交卷時間」排序後，用 **資料 → 資料清理 → 移除重複項目**，以「班級＋座號」為準。
- 換一次測驗時，把舊成績複製到別的工作表保存，再刪掉第 2 列以後的資料即可。

## 注意事項

- **評分方式**：系統在背景把學生的程式模擬執行一遍（最多 20 秒），每筆測資都從角色在中央 (0, 0)、面朝 90 度開始。程式裡有「重複無限次」也可以，系統會以 20 秒時的狀態評分。
- **隨機與互動**：「隨機取數」在評分時每次都會得到同一串數字；鍵盤、滑鼠、目前時間在評分時沒有作用。這類積木適合做練習或作品，不適合當評分題。
- **任何拿到網址的人都能交卷**。有人亂填班級姓名也擋不住，看到奇怪的成績直接刪掉即可。
- **懂技術的學生看得到隱藏測資和答案碼**：評分在學生的瀏覽器裡進行，想偷看答案的人看得到。一般課堂練習通常沒問題。
- 學生的班級、座號、姓名只會存在你的試算表裡，GitHub 上的網頁不會保存任何學生資料。
- 學生交卷時如果送不出去，成績單上會顯示原因，可以改交成績單上的 CSV。
